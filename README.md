# Sanka Queue Manager

Twitch参加型配信の参加者キュー管理 (Electron / Windows・macOS・Linux)。

## 配布者向け (1回だけ)
1. https://dev.twitch.tv/console でアプリを登録 (名前に "twitch" は使えません)
   - OAuthリダイレクトURL: `http://localhost:3000/auth/callback`
   - クライアントの種類: **公開 (Public)**
2. 表示された **Client ID** を `src/config.js` の `DEFAULT_CLIENT_ID` に貼り付け
   (Client Secret は不要・書かないこと)
3. `build/icon.png` を自作アイコン (1024x1024 PNG) に差し替え
4. `package.json` の `author` / `appId` / `productName` を自分の情報に変更

これで利用者は **Client ID の登録不要**、「Twitchでログイン」を押すだけで使えます。

## ビルド
各OSのビルドは、そのOS上で実行します (dmgはmacOSのみ)。

| OS | コマンド | 出力 (dist/) |
|---|---|---|
| Windows | `scripts\build-win.bat` をダブルクリック | インストーラー(.exe) / ポータブル版(.exe) |
| macOS | `./scripts/build-mac.sh` | .dmg (Intel / Apple Silicon) |
| Linux | `./scripts/build-linux.sh` | .AppImage |

手動の場合: `npm install` → `npm run dist:win|dist:mac|dist:linux`
開発起動: `npm start`

## 配布時の注意
- **コード署名なし**だと、Windowsは SmartScreen の警告、macOSは Gatekeeper の警告
  (右クリック→開く で起動可) が出ます。本格配布では署名を推奨します。
  - Windows: コード署名証明書を用意し `CSC_LINK` / `CSC_KEY_PASSWORD` を設定してビルド
  - macOS: Apple Developer Program 加入後、署名+公証 (`build-mac.sh` 内のコメント参照)
- 利用者のTwitchトークンは各自のPC内にのみ保存されます (OSの暗号化機能を使用)。開発者へは送信されません。
- Twitch Developer Services Agreement に従ってください。

## 利用者向け
1. インストールして起動 → 「Twitchでログイン」
2. 受付方法 (コメント/チャンネルポイント/両方) と `!参加` 等を設定して保存
3. 「受付停止」を押して「受付中」に
4. 先頭から「枠」人数がプレイ中。＋1で連続回数を加算、上限で黄・超過で赤。「交代」で最後尾へ (回数リセット)
   - **全員 ＋1**: プレイ中の全員を一括で＋1
   - **上限者を交代**: 上限に達したプレイ中の人を一括で最後尾へ
   - **元に戻す**: 直前の操作 (＋1・交代・削除・全クリア等) を最大30回まで取り消し

## 配信中の操作 (別モニターでアプリを開いて使う想定)
- **キーボード** (アプリが前面の時): `Space` 全員＋1 / `S` 上限者を交代 / `D` 上限者を削除 / `N` 先頭を交代 / `Z` 元に戻す / `R` 受付ON/OFF /
  `↑↓` 行を選ぶ → `Enter` ＋1・`X` 交代・`Delete` 削除・`B` ブロック
- **ホットキー** (ゲーム中など、アプリが裏でも効く): 「連携・設定 → 操作・通知」でONにして、欄をクリックしてキーを押すと割り当てられます。
  初期値は `Ctrl+Alt+1` 全員＋1 / `2` 上限者を交代 / `3` 先頭を交代 / `4` 上限者を削除 / `Z` 元に戻す / `R` 受付 / `M` ミニ表示。他のアプリと重なると登録に失敗し、画面に通知が出ます。
- **ミニ表示**: 「▣ ミニ」ボタン (またはホットキー) で、操作ボタンだけの小さな最前面ウィンドウになります。
- **音通知**: 参加した時・上限に達した時に、アプリ側で音が鳴ります (OBSの配信には入りません)。新着の行は光ります。

## 参加管理
「参加管理」タブで設定します。
- **参加条件** (コメント参加のみ対象。配信者本人は常に可): 視聴者の種類 (サブスク / VIP / モデレーター) で制限、キューの最大人数、
  削除・全クリアで抜けた人の再参加待ち時間。ポイント参加は種類の制限を受けません。
- **ブラックリスト**: コメント・ポイント・(手動追加も) すべて断ります。キューの行の「🚫」やタブから追加。
- **YouTubeライブチャット**: 受付設定の「コメント元」でYouTubeライブまたは「Twitch + YouTube」を選び、配信URLまたは動画IDを入力すると参加コマンドを読み取ります。両方を選ぶと、Twitchチャット・チャンネルポイントとYouTubeチャットを同じキューに取り込みます。公式YouTube APIは使いません。YouTubeのライブチャット画面を読み取る方式のため、YouTube側の変更で動作しなくなる場合があります。チャンネルIDが取得できない投稿者は表示名で識別されます。
- **参加履歴**: 参加回数・通算プレイ回数・最終参加日時。検索したり、そこからキューへ追加・ブロックできます。「最近のできごと」に参加/交代/削除/拒否の記録。
- 断った時は画面に理由が一瞬表示されます (同じ人の連投は30秒に1回まで)。

## 演出 (OBSオーバーレイ)
「OBS見た目」タブの「交代時の演出」。
- **去る人のアニメ** (スライド / フェード / ポップ) と **出番が来た人の強調** (光る / 輝く / 跳ねる)。
- **効果音** (参加 / 出番が来た / 上限到達): 内蔵6種、または好きな音声ファイル (mp3・wav・ogg)。OBSの「ブラウザソース → OBSで音声を制御」にチェックすると音量を調整できます。
  初期値は「なし」(配信に勝手に音が入らないように)。音を出すオーバーレイは1つだけにしてください。
- URLパラメータでも指定可: `leaveAnim` `promoteFx` `sfxJoin` `sfxPromote` `sfxLimit` `sfxVolume`

## 初回ガイドと自動アップデート
- 初めて起動すると、ログイン → 参加方法 → OBS表示 (接続を自動検知) → 動作テスト (テスト参加者の追加) のガイドが出ます。「連携・設定」の下の「使い方ガイド」でいつでも再表示。
- **自動アップデート** (GitHub Releases 利用): 配布者が1回だけ設定します。
  1. `package.json` の `build.publish` の `owner` / `repo` を自分のGitHubに変更
  2. 新版を出す時は `version` を上げ、`git tag v1.3.0 && git push --tags` → GitHub Actions が3OSをビルドして Releases に公開
  3. 利用者のアプリが起動時と4時間ごとに確認し、自動ダウンロード → 「再起動して更新」
  - インストーラー版 (Windows NSIS / Linux AppImage / macOS) が対象です。**ポータブル版は自動更新できません**。
  - macOSの自動更新には、署名+公証済みのアプリが必要です (dmgに加えてzipも出力します)。

## OBS連携
- オーバーレイ: アプリ内の「オーバーレイをOBSへドラッグ」をOBSのウィンドウ(ソース一覧・プレビュー)へドロップ。
  (実体は sanka-overlay.html というファイルで、ポートが変わっても起動時に自動更新されます)
  効かない場合は ソース追加→ブラウザ→ URL(アプリ表示のもの)、幅600 高さ400程度
  - `?count=0` 回数非表示 / `?waiting=1` 待機者も表示
- ドック: OBS メニュー ドック → カスタムブラウザドック → アプリ表示の「操作ドック」URL
- ポート3000が使用中の場合は自動で3001〜に変わります。**表示されるURLを使ってください**。
- アプリ起動中のみ有効です。

## 全OSビルドの自動化
- `setup-all.bat` (Windows) / `setup-all.sh` (macOS・Linux): 展開→Client ID設定→インストール→ビルドまで全自動。
- macOS用dmgはmacOS上でしか作れないため、Windowsからは `.github/workflows/build.yml`
  (GitHub Actions) で Windows/macOS/Linux を一括ビルドできます。

## OBSオーバーレイの見た目
アプリの「OBS見た目」タブで変更でき、OBS側にリアルタイムで反映されます (OBSの設定変更は不要)。
- **テーマ(10種)**: ダーク / ライト / ネオン / サクラ / パープル / ガラス / レトロ / ミニマル / ゴールド / ミント
- **表示スタイル(5種)**: リスト / カード / チップ / 1行バー / スポットライト
- 配置(左・中央・右)、フォント、サイズ(50〜200%)、背景の濃さ、アクセント色、登場アニメ、
  回数・上限・番号の表示、上限者の点滅、待機中の表示、「募集中」表示、ラベル文言
- **シーンごとに別スタイル**にしたい場合は「この見た目の専用URLをコピー」で、設定を含んだURLを取得できます。
  手書きもできます: `http://localhost:3000/overlay?theme=neon&layout=cards&scale=120&showWaiting=1`
  (キー: theme, layout, align, font, anim, scale, opacity, accent(#なし), showCount, showLimit, showIndex,
  showLabel, labelText, waitLabelText, showWaiting, waitingMax, showRecruit, limitBlink)

## リッチカード (アイコン・背景・フレーム付きの参加者表示)
アプリの「カード」タブで、Twitchのプロフィール画像(参加者アイコン)・背景画像・フレーム・名前・回数を重ねたカードを作れます。
- **デザインを選ぶ**: ビルトイン9種 (シンプル / ネオンゲーミング / サクラ / ゴールド / ポップ / レトロゲーム / ポートレート(縦) / ミニバッジ / 透明)。
  選ぶと自動でOBSの表示スタイルが「リッチカード」になります。
- **自分で作る**: 「＋ 新規作成」、またはビルトインを編集 (自動でカスタムとして複製・保存)。
  - 背景: 色・濃さ・画像(ビルトイン6種 or 自分の画像)・表示方法・ぼかし
  - アイコン: 形(円/角丸/四角/六角形/ひし形)、大きさ、縁(単色/二重/レインボー/発光)、アイコン用フレーム画像(透過PNG)
  - フレーム: 単色/二重線/くぼみ/ゴールド/ネオン/ドット絵/四隅、または自作の透過PNG (9分割で角を固定して伸ばせます)
  - 名前・回数: 位置・サイズ・フォント・色・縁取り、回数はバッジ表示も可
  - 上限/超過の表現: 色、フレーム/縁/回数/名前の色変更、発光、点滅
  - **アイコン・名前・回数はプレビュー上でドラッグして配置**できます
- **並べ方**: 「OBS見た目」タブ → 横並び / 縦並び / グリッド(列数) と間隔。配置(左・中央・右)とサイズも共通で使えます。
- **共有**: 「書き出し」でデザインをファイル(.sankacard.json、画像込み)にして、他の人へ渡せます。「ファイルから読み込み」で取り込みます。
- 画像は png / jpg / gif / webp / svg (8MBまで)。カスタムデザインは30個まで。
- プロフィール画像は、Twitchにログインしていると参加時に自動取得します。取得できない場合は名前の頭文字のアイコンになります。
